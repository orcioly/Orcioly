## 📈 Experiência

- **Projetos**

- **App para Eventos**

  - A aplicação foi desenvolvida para facilitar a experiência dos usuários em grandes eventos, oferecendo a apresentação do bilhete, detalhes completos do evento e mapas interativos dos pontos de embarque. Além disso, permite a visualização em tempo real da localização do usuário e do veículo de transporte.
    A solução foi utilizada em eventos de grande porte, como Tomorrowland Brasil, Lollapalooza, Rock in Rio, Stock Car e Arena MRV.

  - **Tecnologias:** NodeJS, React Native, Express, MySQL, TypeScript, Microsserviços, Jest e Swagger.

- **App para Checking em Eventos**

  - Aplicação desenvolvida para a equipe de staff, permitindo a leitura dos bilhetes apresentados pelos usuários em seu aplicativo. O sistema é instalado em um coletor de dados, realizando a leitura em tempo real e oferecendo suporte ao modo offline para operar mesmo sem conexão com a internet. Assim que a conexão é restabelecida, a sincronização dos dados ocorre automaticamente. A solução foi utilizada em eventos de grande porte, como Tomorrowland Brasil, Lollapalooza, Rock in Rio, Stock Car e Arena MRV.

  - **Tecnologias:** NodeJS, React Native, Express, MySQL, TypeScript, Microsserviços, Jest e Swagger.

- **Bot para automatização de relatórios**

  - Sistema desenvolvido sob medida para o cliente e parceiro Bosch. A aplicação tem como objetivo coletar informações sobre vendas e estoque das distribuidoras credenciadas, garantindo maior controle e otimização da gestão.

  - **Tecnologias:** NodeJS, Fastify, MongoDB, TypeScript, Jest e Swagger.

- **E-commerce para vendas de passeios turísticos**

  - Essa aplicação é uma plataforma completa para a venda de passeios turísticos, oferecendo uma experiência intuitiva para clientes e operadores.

    Desenvolvemos essa solução sob medida para um cliente localizado no Vale do Silício, EUA, garantindo alta performance, segurança e integração com meios de pagamento e parceiros do setor de turismo. A plataforma permite a gestão de reservas, emissão de ingressos e acompanhamento em tempo real, proporcionando uma experiência eficiente e inovadora para os usuários.

  - **Tecnologias:** NodeJS, Fastify, NextJS, MongoDB, TypeScript, Jest, Lambda AWS, SES AWS, SQS AWS, SNS AWS, Swagger, Microsserviços e Sentry.

- **Plataforma de criptomoedas**

  - Sistema desenvolvido para uma fintech sediada na Califórnia, EUA.

  A solução é uma plataforma completa para compra e venda de criptomoedas, oferecendo segurança, alta performance e integração com diversas exchanges. O sistema conta com funcionalidades avançadas, como carteira digital, acompanhamento em tempo real das cotações e automação de transações, proporcionando uma experiência ágil e segura para os usuários.

  - **Tecnologias:** NodeJS, NestJS, Angular, MongoDB, TypeScript, Jest, Redis, Kubernetes, Lambda AWS, SES AWS, SQS AWS, SNS AWS, Swagger, Microsserviços e Sentry.

  - **TerraMetrics**

  - Um aplicativo móvel inovador e inteligente para o agronegócio, proporcionando soluções eficientes para otimizar a gestão, monitoramento e produtividade no campo.

  - **Tecnologias:** NodeJS, React Native, Fastify, MongoDB, TypeScript, Jest, Redis, Kubernetes, Lambda AWS, SES AWS, SQS AWS, SNS AWS, Swagger, Microsserviços e Sentry.
